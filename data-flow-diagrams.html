⚡ LUỒNG XỬ LÝ REAL-TIME

┌─────────────────────────────────────────────────────────────────────────────┐
│                       LUỒNG XỬ LÝ THỜI GIAN THỰC                             │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣  USER REQUEST → FRONTEND
    • User action (click, submit, etc.)
    • JavaScript event handler trigger
    • Build request data (body, params)
    • Add Authorization header (Bearer token)
    
    ↓ fetch API (HTTP/HTTPS)
    
2️⃣  HTTP REQUEST → BACKEND
    • Express.js receive request
    • CORS middleware (allow origin)
    • Body parser (parse JSON)
    • Session middleware (OAuth)
    
    ↓
    
3️⃣  AUTHENTICATION LAYER
    • Extract JWT token from header
    • jwt.verify(token, SECRET_KEY)
    • Attach req.user = decoded payload
    • Check vai_tro for admin routes
    
    ↓ if authenticated
    
4️⃣  ROUTE HANDLER
    • Match route path & method
    • Execute controller function
    • Validate request data
    • Business logic processing
    
    ↓
    
5️⃣  DATABASE OPERATIONS
    • Get connection from pool
    • Execute SQL query (prepared statement)
    • For critical operations:
      - BEGIN TRANSACTION
      - Multiple queries
      - COMMIT or ROLLBACK
    • Return result set
    
    ↓
    
6️⃣  EXTERNAL SERVICES (if needed)
    • Send email via Nodemailer
    • Call Payment Gateway API
    • Upload file via Multer
    • Google OAuth API
    
    ↓
    
7️⃣  RESPONSE FORMATTING
    • Build JSON response:
      {
        "success": true/false,
        "data": {...},
        "message": "..."
      }
    • Set HTTP status code
    • Add response headers
    
    ↓ HTTP Response
    
8️⃣  FRONTEND PROCESSING
    • Parse JSON response
    • Check response.success
    • Update UI accordingly:
      - Render data to DOM
      - Show notification
      - Update localStorage
      - Redirect if needed
    
    ↓
    
9️⃣  USER FEEDBACK
    • Display updated content
    • Show success/error message
    • Update badge/counter
    • Enable next action


⏱️  TIMING (Average):
────────────────────────────────────────────────────────
• Frontend → Backend:           50-200ms (network)
• Authentication:                5-10ms (JWT verify)
• Database query:                10-100ms (depends on complexity)
• Transaction:                   20-200ms (multiple queries)
• Email send:                    500-2000ms (SMTP)
• Total round trip:              600-2500ms (typical)


🔄  CONCURRENT OPERATIONS:
────────────────────────────────────────────────────────
• Connection Pool:               Max 10 concurrent connections
• Multiple users:                Handled by Express async/await
• localStorage:                  Client-side, no blocking
• Session:                       Server-side, in-memory store


💾  CACHING STRATEGY:
────────────────────────────────────────────────────────
• Frontend:                      LocalStorage (cart, user)
• Backend:                       In-memory Map (OTP store)
• Database:                      MySQL query cache
• Static files:                  Express.static middleware


🔐  SECURITY MEASURES:
────────────────────────────────────────────────────────
• Password:                      bcrypt hash (10 rounds)
• Token:                         JWT with expiration
• SQL Injection:                 Prepared statements
• XSS:                          Input sanitization
• CSRF:                         SameSite cookie
• CORS:                         Whitelist origins

PUT /api/auth/profile - Cập nhật profile 🔒

GET /api/admin/orders - Quản lý đơn hàng 🔒👑

GET /api/admin/customers - Quản lý khách hàng 🔒👑
